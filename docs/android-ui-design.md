# Android 界面：设计约定

本文是约束，不是描述。界面代码要跟它一致；不一致就是代码 bug，而不是本文过期。

## 一、三层结构

```
Theme.java    token：颜色角色、字号、间距、触控尺寸
Ui / Lists    组件：标题、正文、等宽、按钮、分组卡片、行
*Tab / *Activity  屏幕：Macs / 安装 / 设置 + 推入的 Mac 设置、诊断、日志、显示
```

屏幕里**不许出现字面颜色和字面字号**（`0x1AFFFFFF`、`setTextSize(13f)` 这类）。要加新角色，先加进 `Theme`。

## 二、颜色角色

| 角色 | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `surface` | `#0B0B0D` | `#EFF0F4` | 页面底色 |
| `card` | `#18181C` | `#FFFFFF` | 分组卡片 |
| `cardHigh` | `#222227` | `#F7F8FB` | 卡片之上的卡片（hero、事实块） |
| `onSurface` | `#F2F2F5` | `#121218` | 正文与图标 |
| `variant` | `#A8A8B3` | `#5B5B66` | 次要文字（两套主题都 ≥ 4.5:1） |
| `primary` | 按主题色 | 按主题色 | 唯一的强调色 |
| `primaryContainer` | 按主题色 | 按主题色 | 选中指示器、浅填充 |
| `outline` | `#2C2C33` | `#DCDCE2` | 卡片描边、行间细线 |

主题色五档：蓝 / 紫 / 绿 / 橙 / 红，每档在深色与浅色下各有一对 `primary` / `primaryContainer`。
外观三档：跟随系统 / 浅色 / 深色（`Theme.apply()` 会同时设窗口主题，避免白色对话框与旋转白闪）。

**页面与卡片必须能区分开。** 浅色下 `surface` 与 `card` 亮度差不够时，靠 1dp `outline` 描边兜底；
这条不是装饰——没有描边时整屏变白，行的边界就消失了。

## 三、尺寸

| 项目 | 值 | 依据 |
|---|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24 dp | 4dp 网格 |
| 可触控件最小 | 48dp | 平台无障碍要求 |
| 行最小高度 | 48dp | 同上（有副标题的行自然更高） |
| 实心按钮高度 | 54dp | 低于此值时按钮读起来像一段带底色的文字 |
| 导航栏高度 | 80dp | Material 3 导航栏 |
| 卡片圆角 | 14dp（大卡 16dp） | — |
| 行间细线 | 1dp，左缩进 16dp | 与文字起始对齐 |

## 四、字号（固定角色）

| 角色 | 字号 | 用途 |
|---|---|---|
| 标题 | 24sp 粗 | 屏幕标题、Mac 名称 |
| 状态 | 17sp | 安装进度这类"当前正在发生什么" |
| 行标题 | 16sp | 列表行的名字 |
| 正文 | 15sp | 阅读文本，行距 +3dp |
| 行副标题 | 13sp | 行的说明与当前值 |
| 分节标签 | 12sp 粗，字距 0.06，全大写 | 卡片上方的分组名 |
| 等宽 | 10–11sp | 日志、诊断报告 |

## 五、交互规则

1. **一屏一个实心按钮。** 再多就没有"下一步"了。其余用描边或纯文字按钮。
2. **行必须有点击反馈。** 用 `Theme.ripple`；透明背景的"可点击"等于没反应。
3. **行的细线由卡片自己画**（`SHOW_DIVIDER_MIDDLE`），不在每个调用点手写，否则总有漏的。
4. **列表要能读，不能只靠点进去。** 每行都带当前值（"内存 · 2048 MB"）。
5. **每个 tab 一个主题。** 关于某台 Mac 的设置在它自己的页面上，全局的才进设置。
6. **全屏画面上的控件自动隐藏，但留一条边条。** 边条 44×4dp、居中贴底，点它唤回控件；
   直接消失等于回不去（将来画面区域还要交给 guest 指针）。
7. **进度要有两处表达**：一行大字说状态，一条进度条说"还在动"。
8. **安全区**：所有屏幕经 `Ui.inset()`；全屏显示页另外隐藏系统栏。

## 六、设置里放什么

已实现（都有底层对应物）：

| 设置 | 影响 |
|---|---|
| 主题 / 主题色 | 全应用绘制 |
| 控制条自动隐藏 | 显示页 3 秒后淡出 |
| 驱动 | `adrenotools_open_libvulkan` 打开的 Vulkan 库 |
| 内存 / CPU | `hv_machine_init` 的 `ram_mb` / `ncpus`（下次启动生效） |
| 名称 | Macs 页与 Mac 设置页 |
| 存储清理 | 删除本应用目录下的 `.ipsw` / `.part` / `.part.chunks`（先列清单再删） |
| 日志 / 诊断 | 只读页面 |

不放进设置（因为没有底层支撑，或属于别人的决定）：分辨率与刷新率（guest 自己定）、
缩放比例（由显示页按屏幕适配）、输入映射（等输入注入做完再放，见
`docs/android-integration-plan.md`）。
